**Colab-hosted VLA policies (self-hosted, reached over tunnels):**
- gRPC lane (Tier A/B): LeRobot 0.6.1 `async_inference.PolicyServer` on Colab port 5173 (ngrok TCP); SmolVLA, pi0, pi05, ACT (stock server), Diffusion Policy (`diffusion_policy_server.py` patched launcher), GR00T N1.7 (`groot_n17_server.py` patched launcher)
  - Client: `control/vla_bridge/robot_client.py`, `control/vla_bridge/backends/base_grpc.py`
- HTTP lane (Tier C): per-model Flask adapters on ports 3001 OpenVLA-OFT, 3002 Wall-X, 3003 OpenVLA, 3004 Octo, 3005 RDT-1B, 3006 GR00T N1.5 (ngrok HTTP), `POST {endpoint_url}/action` with base64 PNG images + joint state + instruction
  - Servers: `control/vla_bridge/openvla_server.py`, `openvla_oft_server.py`, `octo_server.py`, `rdt1b_server.py`, `groot_n15_server.py`, `groot_n17_server.py`, `wallx_server.py`, `diffusion_policy_server.py`
  - Client: `control/vla_bridge/backends/base_http_adapter.py`
- Depth service: `control/vla_bridge/fastfs_server.py` (Flask, port 3000, Fast-FoundationStereo weights via gdown) consumed by `control/vla_bridge/depth_camera.py` via `requests`
- Hosted by one notebook per backend in `control/vla_bridge/notebooks/` (generated by `scripts/build_colab_notebooks.py`); index, GPU types, gated licences and smoke/episode commands in `control/vla_bridge/notebooks/README.md`; process/port management via `control/vla_bridge/colab_server_utils.py`; local smoke test `python -m vla_bridge.backend_smoke`

**Tunneling:**
- ngrok via `pyngrok==8.1.2` (installed in Colab notebook) - separate tunnels for gRPC PolicyServer and HTTP adapters
  - Auth: ngrok token read from Drive `MyDrive/SoARM-Research/.ngrok_token` or prompted in the notebook (not in repo); HF token likewise from `.hf_token`
  - Every notebook has a teardown cell; open tunnels must be closed each session (T-11-08)
