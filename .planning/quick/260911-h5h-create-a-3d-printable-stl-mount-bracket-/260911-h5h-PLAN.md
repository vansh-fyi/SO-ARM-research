**Boolean CSG build order (verified to work in this exact sequence with `engine="manifold"` on every op):**
1. Extrude the R2-rounded 145x66 profile to 4mm thickness -> `plate`.
2. `plate.difference(window_box)` -> `frame` (window box overshoots z by ~0.5mm each end).
3. `frame.union(tab)` for each of the 4 tab boxes -> `frame_tabs`.
4. `frame_tabs.difference(lens_cyl)` for each of the 2 lens-clearance cylinders.
5. For each of the 4 hole positions: `.difference(through_hole_cylinder)` then `.difference(hex_nut_pocket)` (hex pocket extruded from just below z=0 up to z=2.5+overshoot).
6. Export the final solid as binary STL.

This exact pipeline was run end-to-end during planning and produced: `is_watertight=True`, `euler_number=-8` (correct topology: 1 handle from the window + 4 handles from the through-holes = genus 5 closed manifold), bounding-box size exactly [145, 66, 4], volume ≈ 30351 mm^3, valid binary STL header.
