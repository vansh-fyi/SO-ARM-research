- [x] CONSTRAINT: sys.modules numpy caching — After torch imports numpy 2.0.2 in Cell 2, `import numpy` in later cells returns the cached version even after pip reinstall. Always use `subprocess pip show numpy` to check on-disk version, never `import numpy; print(np.__version__)`.
- [x] CONSTRAINT: numpy pin ordering — numpy<2 MUST be installed LAST in Step 3. Any package installed after it (e.g. opencv 4.10+) will upgrade numpy back to 2.x. Also pin opencv<4.10 to prevent the conflict entirely.
- [x] CONSTRAINT: flash-attn wheel — cu118 wheel FAILS on CUDA 12.x (libcudart.so.11.0 absent). cu121 does NOT exist at v2.6.3. Use cu123 wheel — CONFIRMED WORKING on CUDA 12.1. Step 6 already implements this.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Import-based version check | Using `import numpy; np.__version__` after pip reinstall returns cached sys.modules version, not on-disk | blocking | Use `subprocess pip show numpy` — always checks disk |
| numpy pin before opencv | Installing numpy<2 before opencv causes opencv 4.10+ to upgrade numpy back to 2.x | blocking | numpy<2 pin must be the FINAL pip command in Step 3 |
| flash-attn source compile | `pip install flash-attn --no-build-isolation` compiles CUDA kernels for 60-90 min then OOMs T4 | blocking | Use pre-built wheel URL from GitHub releases |
| conda on Colab | Colab has no conda; conda commands fail silently | advisory | Use pip only; check binary wheel availability first |
