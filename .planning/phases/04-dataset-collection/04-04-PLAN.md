<objective>
Implement DATA-03's normalization statistics computation and run it against the real
dataset produced in 04-02, producing a `dataset_statistics.json`-shaped artifact Phase 6
can overlay directly.

Purpose: DATA-03 requires SOARM-specific action/observation normalization statistics
"computed from the collected dataset, not copied from Panda." Research confirms OpenVLA's
own normalization convention (q01/q99 percentile bounds, "BOUNDS_Q99") is what
`oft_backend.py` already consumes via its `dataset_statistics.json` overlay — matching
that exact schema means Phase 6 reuses `oft_backend.py`'s existing `json.load()` +
dict-key overlay pattern instead of writing a second stats-loading code path.

Output: `normalization.py` (pure-numpy stats computation, no sim/robomimic dependency)
and the real on-disk artifact: `LIBERO/libero/datasets/soarm_spatial/dataset_statistics.json`.
</objective>
