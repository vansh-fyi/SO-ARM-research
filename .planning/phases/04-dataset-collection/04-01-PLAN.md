<objective>
Build the shared recording infrastructure for Phase 4's dataset pipeline: a reusable
SOARM-env-plus-DataCollectionWrapper builder, and an HDF5 writer that turns raw
recorded states/actions into a robomimic-schema `demo.hdf5` with real regenerated
image observations under LIBERO's renamed obs keys. This is the foundation every
other Phase 4 plan (scripted collector, teleop, replay verification, normalization)
builds on — per D-05, it lives in the new `LIBERO/libero/libero/datasets/` package,
not `explorations/` or a modification of the existing npz-based scripts.

Purpose: DATA-01 requires the scripted collector to land demos in valid robomimic
HDF5 format with image observations present. Neither of this repo's existing
prior-art scripts (`LIBERO/scripts/collect_demonstration.py`,
`libero_100_collect_demonstrations.py`) write an `obs/` group at all — they only
write `states`/`actions`. This plan adds exactly that missing piece, reusing this
repo's own `ControlEnv.set_init_state()`/`regenerate_obs_from_state()` primitive
(already proven in Phase 2/3) rather than reimplementing state-based observation
regeneration.

Output: `LIBERO/libero/libero/datasets/` package (scaffold + `raw_recorder.py` +
`hdf5_writer.py`), proven end-to-end by a real local-sim integration test.
</objective>
