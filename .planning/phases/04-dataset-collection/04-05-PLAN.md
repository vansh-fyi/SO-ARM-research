<objective>
Implement DATA-04's keyboard-only teleoperation interface (D-02) and prove, with a real
human-operated session, that it produces demonstrations in the identical HDF5 schema the
scripted collector (04-02) produces — reusing the same `raw_recorder.py`/`hdf5_writer.py`
infrastructure from 04-01, not a parallel implementation.

Purpose: DATA-04 requires a human operator be able to record SOARM demonstrations via
teleoperation, landing in the same HDF5 format as the scripted path. Research confirms
`robosuite.devices.Keyboard` + `input2action` + `DataCollectionWrapper` are directly
reusable with zero SOARM-specific changes — `input2action` reads generic
robot/controller state, and SOARM's `Soarm101` class already exposes the same
`ManipulatorModel` interface Panda does. D-02 explicitly excludes SpaceMouse.

Output: `teleop.py` (keyboard-only collection loop) and a real, human-completed
episode on disk, schema-matched against the scripted path and determinism-verified.
</objective>
