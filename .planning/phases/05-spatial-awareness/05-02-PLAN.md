| MuJoCo depth buffer -> depth_xyz.py back-projection math | numerical sensor data (not adversarial-untrusted in this research context, but calibration-fragile) crossing into projective-geometry code |
| segmentation-derived instance ID -> object-identity assumption | object_pixel_centroid trusts the segmentation channel's ID mapping to correctly identify "this object" |
