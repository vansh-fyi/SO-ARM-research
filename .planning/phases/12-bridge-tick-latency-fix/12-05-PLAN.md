Implement the first of a 3-step, user-approved extension to Phase 12 (per `12-CONTEXT.md`
D-07, added 2026-09-26 -- see `12-UAT.md`'s 4th Gaps entry for the full research background):
a checkerboard-based stereo calibration module for the AR0144 stereo camera, producing a
saved calibration file that Plan 12-06's `depth_camera.py` will load to rectify live stereo
pairs and derive the flattened 3x3 intrinsics + baseline (meters) NVIDIA's
Fast-FoundationStereo (FastFS) requires as input alongside a rectified, undistorted pair.

This module is standalone: it reuses the existing, unmodified `StereoSplitCamera`
(`control/vla_bridge/stereo_camera.py`) for live capture -- never a second, independent open
of the AR0144, which the camera's own docstring documents as unsupported -- and has zero
dependency on `run_vla_episode.py`, `robot_client.py`, or the bridge/PolicyServer path. It
can be run and verified entirely on its own, ahead of Plan 12-06.

Purpose: Produce trustworthy stereo geometry (not an unvalidated guess) so a later depth
computation can be human-verified against a known real-world distance -- stricter than the
StereoPatch paper's own validation, which only checks closed-loop task success rate with no
ground-truth depth check at all.
Output: `control/vla_bridge/stereo_calibration.py` (new module) and
`control/test_stereo_calibration.py` (new, hardware-free test coverage). A human-run live
calibration session against the real checkerboard, producing a real calibration JSON file on
disk, confirmed via this plan's Task 2 human-check.
