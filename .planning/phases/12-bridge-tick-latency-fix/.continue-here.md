# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: Background-thread output is unrecoverable after the fact — `policy_server.ipynb`'s Step 3 runs `serve(config)` inside `threading.Thread(target=serve, ...)`. Jupyter/Colab only captures stdout/stderr for whichever cell is *synchronously executing* at the moment the thread prints something — once that cell finishes, later thread output vanishes from every saved cell output, even after saving the notebook. This is exactly why Test 7's 3 crashes tonight left no recoverable traceback. **Before attempting Test 7 again, add a log-file redirect to Step 3's cell** (e.g. `contextlib.redirect_stdout`/`redirect_stderr` to `/content/policy_server.log`, or Python `logging` with a `FileHandler`) so a future crash is actually diagnosable. Do not re-attempt the live episode run without this fix in place — you will just recreate the same "no error visible" dead end.

**Do not proceed until this box is checked.**
