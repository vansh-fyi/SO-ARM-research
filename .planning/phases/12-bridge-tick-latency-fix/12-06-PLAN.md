<objective>
Implement steps 2 and 3 of the user-approved 3-step depth-calibration extension to Phase 12
(per `12-CONTEXT.md` D-07): document a Colab-hosted Fast-FoundationStereo (FastFS) depth
endpoint, build a local `depth_camera.py` client that rectifies a live AR0144 stereo pair
(using Plan 12-05's calibration file), downsamples it to FastFS's input constraints, and
requests a metric depth map from that endpoint -- then wire a depth-RECORDING step into
`run_vla_episode.py`'s per-tick loop, alongside Plan 12-03's `overhead_left`/`overhead_right`
diagnostic recording.

FastFS does not rectify internally and is CUDA-GPU-only with no CPU inference path; this
project's Mac client has no CUDA GPU, so depth inference runs on the SAME Colab runtime
already hosting the SmolVLA `PolicyServer` (documented in `policy_server_launch.md`), reached
over a second HTTP tunnel.

Depth is recording-only this phase (per D-08): it is saved to the episode output directory
and referenced in `episode.jsonl`, but is NEVER added to the observation dict
`BridgeActionSource`/`connect_bridge` send to the policy -- the current SmolVLA checkpoint has
no depth input feature at all, and no fusion architecture exists yet to consume it usefully.
Per D-09, StereoPatch's own custom RGB-depth fusion architecture (DeFM depth encoder +
cross-attention tokens) has no public code release and is explicitly out of scope -- this plan
implements ONLY the calibrated-depth-computation half; fine-tuning a depth-aware checkpoint
and the fusion architecture itself are both deferred to a later milestone phase, not scheduled
here.

Purpose: Prove the calibrated depth pipeline actually produces trustworthy metric depth via a
human-verifiable, real-world-distance checkpoint -- stricter than the StereoPatch paper's own
(indirect, task-success-only) validation -- and make that depth available for inspection
without touching the live control/inference path this phase.

`control/vla_bridge/policy_server_launch.md`, `control/vla_bridge/io_logger.py` and

    Add `class DepthCameraClient`: `__init__(self, calibration: "stereo_calibration.

    `endpoint_url`/`max_width` and calls a private `_build_rectification_maps(calibration)`
    that: reshapes `calibration.left_K`/`right_K` into `(3,3)` numpy arrays, `left_D`/
    `right_D` into flat arrays, `R` into `(3,3)`, `T` into a flat 3-vector, `image_size` into
