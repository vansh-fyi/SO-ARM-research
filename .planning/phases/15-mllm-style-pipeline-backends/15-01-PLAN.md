## Phase Goal

**As a** researcher benchmarking general reasoning models as raw-autonomy robot controllers, **I want to** select an MLLM backend with `--backend` and have it turn a task prompt, camera views, depth and joint state into raw absolute joint-target chunks that drive the SO-ARM101 through the unchanged safety validator and logger, **so that** Phase 16 can compare MLLM raw-autonomy behavior against trained VLA policies using per-call audit records instead of guesses.

This slice: a researcher can run a scripted fake MLLM end to end through the real loop and read the per-chunk trace in `episode.jsonl`.
