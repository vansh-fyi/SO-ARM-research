## Phase Goal

**As a** researcher benchmarking general reasoning models as raw-autonomy robot controllers, **I want to** select an MLLM backend with `--backend` and have it turn a task prompt, camera views, depth and joint state into raw absolute joint-target chunks that drive the SO-ARM101 through the unchanged safety validator and logger, **so that** Phase 16 can compare MLLM raw-autonomy behavior against trained VLA policies using per-call audit records instead of guesses.

This slice: a researcher can see, offline, exactly what the model will be shown (prompt, schema, URDF text) and, with the rig on, capture one real set of images plus depth heatmap and grid without spending on any model.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control machine -> FastFS Colab endpoint | Raw stereo frames leave the machine; only one request may be in flight |
| control machine -> third-party model provider (via later plans) | Camera images, depth heatmap and grid are sent to a provider |
| depth error text -> prompt | Network errors can contain the rotating endpoint URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-14 | Information disclosure | depth failure text reaching the model prompt | medium | mitigate | Failed or missing depth always yields the fixed note "Depth unavailable this call."; error text goes only into truncated meta (tested with a URL-bearing error) |
| T-15-15 | Denial of service | HTTP 429 from overlapping depth requests | medium | mitigate | One synchronous depth call per chunk, 2 retries with 2 s sleeps, failure never blocks the chunk; main() never starts a second depth caller (Plan 15-03) |
| T-15-16 | Information disclosure | lab images and depth sent to a third party | medium | accept | Operator notice printed at build time (Plan 15-06) and retention documented per provider; sidecars stay in git-ignored control/outputs |
| T-15-17 | Tampering | misleading kinematics context (unverified joint sign) | medium | mitigate | URDF text omits any sign claim; include_urdf toggle changes the prompt hash and is logged per call; human sign check scheduled in Plan 15-10 |
