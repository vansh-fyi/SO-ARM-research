## Phase Goal

**As a** researcher benchmarking general reasoning models as raw-autonomy robot controllers, **I want to** select an MLLM backend with `--backend` and have it turn a task prompt, camera views, depth and joint state into raw absolute joint-target chunks that drive the SO-ARM101 through the unchanged safety validator and logger, **so that** Phase 16 can compare MLLM raw-autonomy behavior against trained VLA policies using per-call audit records instead of guesses.

This slice: a researcher can open any call's sidecar directory and see the exact prompt, images, raw response, cost and settings, with the key provably absent.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider response/exception text -> record and sidecar files | Third-party payloads and error strings may echo credentials |
| model output -> filesystem | Anything model-derived must not influence paths |
| lab images -> disk | Sidecars retain exact camera frames sent to a third party |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-10 | Information disclosure | records, sidecars, error strings | high | mitigate | Central redact()/redact_text() on every record, sidecar text and error; header-key value redaction; test scans every produced file for the secret |
| T-15-11 | Tampering | sidecar path construction | high | mitigate | Integer chunk id, fixed filename and role whitelists validated before any write; ValueError on anything else (test with traversal attempts) |
| T-15-12 | Denial of service | disk full or unwritable output directory | medium | mitigate | finalize never raises; failure becomes sidecar_error, loop keeps holding/running |
| T-15-13 | Information disclosure | camera images retained on disk | low | accept | Sidecars live under git-ignored control/outputs; provider retention is disclosed at build time (Plan 15-06) |
</threat_model>
