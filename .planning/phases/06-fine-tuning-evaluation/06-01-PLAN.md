<objective>
Build a custom, testable robomimic-HDF5-to-RLDS converter module (TUNE-01, D-04/D-05/D-06) that reads this project's own `put_the_cream_cheese_in_the_bowl_demo.hdf5` schema (agentview_rgb, eye_in_hand_rgb, joint_states+gripper_states, actions -- Phase 4's `hdf5_writer.py` output) and writes a genuine `tensorflow_datasets`-loadable RLDS dataset directory that Plan 06-02's `finetune.py` invocation will train against.

Purpose: TUNE-01 requires the collected dataset to be usable by OpenVLA-OFT's fine-tuning pipeline, which loads training data exclusively via `tfds.builder(name, data_dir=...)`. Output: `rlds_converter.py` (schema validation + per-episode HDF5 loading + TFDS writer, all locally testable except the final TFDS byte-write which needs Colab's `tensorflow_datasets`) and `test_rlds_converter.py` (local automated coverage for validation/loading, skip-guarded coverage for the TFDS write).
</objective>
