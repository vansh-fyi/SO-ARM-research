## Phase Goal

**As a** researcher building the SoARM VLA data/fine-tuning pipeline, **I want to** depth frames to be recorded into the same HDF5 dataset as RGB/proprio, **so that** a future demo collection run (Phase 9) produces a depth-augmented dataset without any writer-side gaps.

This plan is the depth-to-HDF5 slice: after it lands, a researcher can record a demo and inspect a real, persisted `agentview_depth` array on disk — a complete, independently useful capability (it does not require the RLDS conversion in 07-03 to be valuable; a robomimic `SequenceDataset` reader could already consume it). It is independent of 07-01 (camera recalibration, zero file overlap) and is a prerequisite for 07-03 (RLDS conversion reads the exact key/dtype/shape convention this plan establishes).
