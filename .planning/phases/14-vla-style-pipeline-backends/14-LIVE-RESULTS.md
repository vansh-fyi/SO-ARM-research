# Phase 14: Live Verification Results

Live backend smoke evidence for the 14 VLA backends, gathered before the Phase 14 hardware UAT
(`14-UAT.md` tests 1, 2 and 6-18). Each smoke runs the backend's real registered factory and real
`ActionSource` against its live Colab server or the Gemini API, with synthetic camera frames and a
synthetic joint state. No robot, serial port or camera is opened and no action is sent
(`control/vla_bridge/backend_smoke.py`, quick task 261004-dz7). Every result cell starts as PENDING.

Rules for this file:

- Keys and tokens (HF, ngrok, GEMINI_API_KEY) live only in the operator's shell or the Colab
  token prompt. No key, token or key-shaped string is ever written here, in a backend config or
  in any committed file.
- A backend the user chooses not to run is marked "deferred by user (YYYY-MM-DD)", never left
  PENDING.
- A backend_smoke PASS is a precondition for that backend's 14-UAT hardware test, not a
  replacement for it. The UAT still needs the real robot and cameras.
- Record the smoke's own PASS/WARN/FAIL lines; do not paraphrase a FAIL into a WARN.

Notes on reading the output:

- The synthetic joint state is the midpoint of every calibrated joint range. A model whose
  first action is far from that pose may produce validator clamp flags (WARN). Only a
  `rejected non-finite` / `stale observation` flag or a missing joint is a FAIL.
- On the Gemini lane the synthetic wrist frame contains no real object, so a hold
  (`gemini-er-conversion-held-position`) can be a correct model answer. Record it, and use
  14-UAT test 16 on hardware for the servo direction.
- gRPC latency is the observation-to-action age the validator checks against STALE_ACTION_S
  (30 s). Above 5 s is WARN, above 30 s is FAIL. The time spent waiting for a cold server's first
  chunk is printed separately.

## 3. Findings

Recorded 2026-10-25. A smoke PASS proves plumbing only (synthetic images and joint state); task
behaviour is judged in the 14-UAT hardware tests.

1. **Coverage:** 10 of 14 backends PASS (smolvla, pi0, pi05, act, diffusion, groot-n17,
   openvla-oft, openvla, gemini-robotics, gemini-robotics-2). wallx, octo, rdt1b and groot-n15 were
   deferred by the user on 2026-10-18; the backends and their notebooks are kept.
2. **Colab transformers drift (14-UAT tests 6, 7, 20):** Colab ships transformers >=5.9, which
   removed `cache_position` from `create_causal_mask`. lerobot 0.6.1's pi0/pi05 still pass it, so
   every inference fails inside the PolicyServer. Fix: `transformers==5.5.4` (inside lerobot 0.6.1's
   declared `>=5.4,<5.6`), torch unchanged at 2.11.0+cu128. All gRPC notebooks now pin it after
   installing lerobot; test 20's "transformers 5.4-5.6" check covers it.
3. **pi0 checkpoint ships `compile_model: true` (14-UAT test 6):** max-autotune made the first
   inference take 465 s, and every reconnect (the PolicyServer reloads the policy per client)
   failed with a CUDA-graph mempool error. `grpc_pi0.ipynb` snapshots the checkpoint to
   `/content/ckpt/pi0_so101_nocompile` with `compile_model=false`; the hardware episode must pass
   that path as `--checkpoint`.
4. **gRPC first-action latency:** 5.85-14.66 s on the cold first inference (WARN against the 5 s
   budget, well under the 30 s stale limit). Judge steady-state latency in the hardware episodes.
5. **gRPC validator line vs bridge clamps:** on the gRPC lane the smoke validates the action after
   `robot_client.pop_validated_action()` has already clamped it, so "accepts it unchanged" appears
   next to clamp flags the bridge appends to `model_version` after the `@`. pi0, pi05 and act hit
   the 40 deg per-step cap from the synthetic pose; act clamped 4 joints (it asked for
   shoulder_lift -68 deg and elbow_flex 76 deg). Watch act's first steps in test 8.
6. **Stale server on the gRPC port:** a stock PolicyServer left on 5173 answered the diffusion
   smoke and produced an empty `Error in StreamActions:`. The new notebooks report ready only when
   their own process owns the port.
7. **groot-n17 default checkpoint replaced (14-UAT test 18):** `tsangb34/groot-n17-so101-cube-drawer-40k`
   was removed from HF. The default is now `tsangb34/groot-n17-so101-soccer-red_bowl-40episodes`
   (front + wrist, relative joints, degrees, Apache-2.0, chunk 16); test 18's command must use it.
8. **openvla-oft venv drift (14-UAT test 2):** openvla-oft's unpinned dependencies no longer import
   under tensorflow 2.15; pinned in commit 3d8adda (see the openvla-oft row).
9. **Licensing (14-UAT test 5):** the user accepted `toasta18/openvla-so101-cylinder` (no licence)
   for UAT on 2026-10-18. `sapanostic/octo-so101-3hz-finetune` is still undecided (octo deferred).
10. **Gemini latency:** 8.45 s and 8.67 s against a 10 s client timeout, plus one 10.32 s timeout.
    Lowering `thinking_level` from medium to low is pending a user decision before tests 14-17.
11. **HTTP repeat actions:** openvla and openvla-oft returned identical actions on all 3 steps,
    which is expected from deterministic decoding of the same synthetic input.
