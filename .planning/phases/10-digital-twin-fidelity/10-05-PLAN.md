    1. Send a known CLOSE command to the real follower arm's gripper, e.g.
       `python control/joint_jog.py /dev/cu.usbmodem5B8E1139151 soarm_follower_02 gripper 20`
       (confirm the port/ID against `control/COMMANDS.md`'s current device table first — macOS can
       reassign the port suffix on replug) and note which direction the real jaws move.
    2. Translate that command into the sim's `-1`(open)/`+1`(closed) convention per D-08 — a CLOSE
       command is `+1` in `SoarmGripper.format_action`'s EXTERNAL `action` argument (do not read
       `current_action`'s sign — see Pitfall 2).

       call with the gripper action dimension set to `+1` on a `Soarm101` LIBERO env) and observe which
       direction the sim jaws move.
    4. Confirm both moved the SAME direction (both closed, or repeat with an open command if that's
       easier to observe — either direction is a valid comparison as long as it's the same command on
       both sides).
  </how-to-verify>
