Build the JSON Lines I/O logger (VLAHW-03, per D-04's chosen log format) and the real-hardware control-loop harness (`run_vla_episode.py`) that wires it together with Plan 11-01's safety validator, real camera capture, and a software-keyboard-interrupt e-stop (per D-03 — no new physical hardware) — driving the REAL SO-ARM101 end-to-end today, using a pluggable `ActionSource` interface. Purpose: Every piece Phase 11 needs downstream (bridge wiring, live episode) depends on this harness already working safely against the real robot. Building it now, gated by a scripted stand-in, lets the safety-critical control loop (retry, logging, e-stop) get proven on hardware before the added complexity and non-determinism of a live network bridge.
Output: `control/vla_bridge/io_logger.py` (JSONL writer + per-camera frame capture) and `control/run_vla_episode.py` (the real-hardware entrypoint), both covered by tests using mocked hardware.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control loop ↔ physical robot | Any action source (scripted today, network-bridged in Plan 11-04) writes to real servos through this loop |
| e-stop ↔ network/bridge state | The e-stop must work even if a future network bridge (Plan 11-03/04) is completely dead |
| log writer ↔ disk | The JSONL log must survive a process crash without corrupting already-written data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-04 | Denial of Service | e-stop path | critical | mitigate | E-stop is implemented as a local `try/except KeyboardInterrupt` in `run_vla_episode.py`'s own process — per D-03, it has zero dependency on any network/Colab/bridge state, matching `control/keyboard_joint_control.py`'s already-UAT-verified pattern; `test_keyboard_interrupt_triggers_return_to_start_before_disconnect` pins this |
| T-11-05 | Tampering | servo read/write comms | medium | mitigate | Reuses `keyboard_joint_control.py`'s existing retry-with-backoff (`read_positions`) and log-and-hold (`except (ConnectionError, RuntimeError)`) patterns verbatim rather than introducing new, unverified comms-handling code |
| T-11-06 | Repudiation | JSONL log durability | low | mitigate | Every `write_step()` call flushes immediately; `test_log_is_durable_across_a_simulated_mid_episode_crash` (Task 1) proves partial episodes remain readable after an unclean exit |
