## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pip install (Colab side) | `pyngrok` install happens on the Colab notebook, not this repo's `control/.venv` — but the legitimacy risk and human-verification requirement are identical regardless of where the install runs |
| HF Hub model checkpoint download | Community-uploaded model weights are a different risk profile than pip packages — safetensors format avoids arbitrary code execution, but config/camera-key mismatches are a functional (not security) risk this plan's Task 1 addresses |
| ngrok tunnel | A public internet-reachable endpoint into a Colab-hosted `PolicyServer` |
